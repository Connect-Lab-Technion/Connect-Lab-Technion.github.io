About the simulations

Five movies simulate the bearing-based controllers used in the lecture. The leader-placement movie is a geometric animation of bearing-preserving configurations, not a simulated controller trajectory. Target bearing directions stay fixed in a common reference frame; the maneuvers involve translation and positive scaling, without rotation.

The 2D maneuver uses the graph, gains and initial conditions of the example accompanying Zhao and Zelazo, Translational and Scaling Formation Maneuver Control via a Bearing-Based Approach, IEEE Transactions on Control of Network Systems (2017), Fig. 4. The 3D movie is a new planned contraction through a square aperture with two leaders and six followers, using the acceleration-feedback law in Eq. (10). This controller does not plan paths or avoid obstacles.
